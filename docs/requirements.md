# 需求

星辰電腦（NSZPC，高雄的客製化電腦店）的官網：讓客人看推薦配單、出機紀錄、技術文章，找到聯絡方式；讓店家自己改這些內容。
庫存、進貨、訂單、報價單、檢測表不在這裡，在內部管理系統 DPOM（https://dpom.bluz.dev，[ADR 0003](decisions/0003-dpom-owns-internal-data.md)）。

目前網址（給客戶 demo）：<https://nszpc.bluz.dev>。

## 前台（給客人看）

導覽列：首頁、出機紀錄、分類總覽、技術文章、聯絡我們。footer：探索（推薦配單、出機紀錄、分類總覽、技術文章）、聯絡星辰（聯絡管道）、門市（地址、標語）、版權。

- **首頁**（`/`）：
  1. 「星辰電腦」大標＋首頁主標題，下面一排分類照片（點了到分類頁），最後是「全部分類」
  2. **探索推薦配單**：橫向卡片列，名稱、價格「起」、進一步了解、LINE 詢問（聯絡管道裡名稱有 LINE 的那個，沒有就跳到聯絡我們）。沒有配單（或讀不到）整段不顯示
  3. **近期出機**（標題是網站文字的「首頁近期出機標題」）：最新 12 筆（顯示 8 張）的直式照片卡，點了跳出視窗看照片和配備。沒有出機紀錄（或讀不到）整段不顯示
  4. **跟星辰買電腦，最好。**：首頁統計數字＋服務流程卡
  5. **客戶怎麼說**：客戶回饋
  6. **聯絡我們**（`/#contact`）：線上詢問（聯絡管道）、到店諮詢（地址＋Google 地圖）
- **分類總覽**（`/categories`）：分類卡，可以用快速標籤、關鍵字篩選
- **分類詳細**（`/categories/item/:id`）：介紹、重點、推薦、FAQ；標籤對得上的推薦配單（沒有對得上的就不顯示那一段）
- **推薦配單**（`/builds/item/:id`）：介紹、需求說明、規格、價格、影片
- **出機紀錄**（`/orders/tags`）：全部的出機紀錄，用標籤篩選，選多個標籤是 AND（都要有）。標籤來源是網站文字的「出機紀錄統一標籤庫」加上出機紀錄本身的標籤。
  每張卡片上面是第一張照片
- **出機詳細**（`/orders/item/:id`）：品名、需求說明、標籤（點了到出機紀錄頁篩選）、出貨日期、交機地區、狀態、成交金額（售價，0 不顯示）、第一張照片（右邊）、
  更多照片（超過一張才有這段）、配備、影片。用 id 直接查那一筆，每一筆都打得開；找不到顯示「找不到這筆出機紀錄」
- **技術文章**（`/blog`）：可以用標籤和關鍵字篩選；**文章**（`/blog/:slug`）：段落、條列、標籤、影片

規則：

- **前台不顯示給管理者看的字**：不寫「可在後台編輯」「待補充」「未標示」，也不放後台的連結（管理員從 DPOM 的側欄或直接打 `/admin` 進去）
- **沒填的就不顯示**：規格沒填的那一格不顯示；沒有影片就整段「影片」不顯示
- **公開的出機紀錄不顯示服務費**，只顯示售價（`/api/public/orders` 本身就不回 `serviceFee`）；也沒有客人的資料
- **版號、更新紀錄只在後台**（[ADR 0008](decisions/0008-version-in-admin-only.md)）
- **不顯示假資料**：出機紀錄、推薦配單讀不到時，首頁那一段不顯示，出機紀錄頁、出機詳細頁、推薦配單頁寫「暫時載入不了，請稍後再試」，
  不拿範例資料充數（[ADR 0009](decisions/0009-public-order-by-id-and-no-fake-data.md)）。網站文字、分類、技術文章讀不到時才用前端內建的內容（`frontend/src/data/`、`publicSiteContent.ts`）
- **出機紀錄沒有照片**：首頁的照片卡、跳出視窗、出機紀錄頁、出機詳細頁都顯示淺灰底＋主機圖示的空白格（`components/OrderPhoto.tsx`），
  不拿別台主機的照片充數；照片讀不到（壞掉的網址）也一樣
- 分享到 LINE、FB 時，出機紀錄、推薦配單、分類、文章都有自己的標題、說明、照片；文章不跑 JS 也讀得到內容（[ADR 0005](decisions/0005-share-preview-and-seo.md)）
- 手機（393px）和電腦（1440px）都要好看

## 後台（`/admin`，給店家用）

登入用 Cloudflare Access：輸入管理員的 email、收信拿驗證碼，只有 `ADMIN_EMAILS` 裡的 email 進得去（[ADR 0002](decisions/0002-cloudflare-access.md)）。
左側選單（手機是上方分頁），下面有「內部管理系統」（DPOM）、「查看官網」、登入的 email、版號、切換帳號、登出。

- **出機紀錄**（`/admin#orders`，預設這頁）：官網上的出機案例。通常是在 DPOM 的訂單按「發布到官網」帶過來，這裡可以改文字或手動新增、刪除。
  欄位：日期、品名、需求說明、地區、售價、服務費（後台才有）、狀態（待處理、配送中、已送達、已取消）、標籤（從統一標籤庫選）、照片、八項規格、YouTube 網址。
  上面有這個月的售價區間分佈；每列有「編輯」「在官網上看」，刪除收在「更多」
- **推薦配單**（`/admin#builds`）：新增、編輯、刪除；名稱、簡介、需求說明、價格、成交日期、徽章、標籤、圖片、規格、配件、YouTube 網址
- **分類總覽**（`/admin#categories`）：新增、編輯、刪除；標題、摘要、主／次分類、標籤、重點、介紹、主圖、推薦、FAQ
- **技術文章**（`/admin/blog`）：新增、編輯、刪除；`slug`（英文小寫和 `-`，文章網址）、標題、摘要、封面、發布日期、更新日期、作者、閱讀分鐘數、標籤、段落、YouTube 網址
- **網站文字**（`/admin#siteContent`）：上方快速跳到各區塊，儲存列固定在畫面下方，存了前台馬上更新。區塊：
  首頁（主標題、聯絡我們描述、近期出機標題）、首頁統計、分類總覽（主描述、快速標籤）、出機紀錄統一標籤庫、出貨流程、客戶回饋、聯絡管道、Footer（地址、標語）
- **更新紀錄**（`/admin/changelog`）：點側欄最下面的版號進去，有新版時版號旁邊顯示 NEW

規則：

- **網站文字的舊欄位**：前台已經不顯示的 13 個欄位（`backend/src/lib/types.ts` 的 `RetiredSiteContentKey`：首頁主標籤、首頁各區塊副標、品牌作品集標題和內容、品牌頁副標、服務項目、聯絡地址電話 LINE）
  不在後台表單裡，但**資料庫裡的值保留**：存檔時沒帶的就沿用原本的值（[ADR 0006](decisions/0006-remove-admin-generators.md)）
- 估價單、出機檢查單不在官網後台，用 DPOM 的報價單、檢測表
- **文章的 `slug` 不能重複**（文章網址是 `/blog/<slug>`），新增、編輯時跟別篇一樣就存不進去，顯示「Slug「…」已經有別篇文章在用了，請換一個」
- **文章的「更新日期」照後台填的存**：sitemap 的 `lastmod`、文章頁的 `article:modified_time` 都用它，改了文章記得把更新日期改成今天
- **刪出機紀錄會連照片一起刪**（R2 裡這筆的照片，別筆還在用的不刪，[api.md](api.md#delete-apiadminordersid)）
- 輸入檢查在 `backend/src/lib/validation.ts`（必填欄位見 [api.md](api.md)），沒過回 422，後台顯示哪些欄位有問題
- 兩個人同時存，後存的會自動重讀重做，不會蓋掉前一個人改的（[architecture.md](architecture.md#資料整份-json)）；網站文字也是（舊欄位的合併在同一個交易裡）

## DPOM 發布出機紀錄

DPOM 的訂單按「發布到官網」：帶品名、需求說明、地區、售價、狀態、規格、標籤（可以選官網用過的）、照片（最多 10 張、每張 10MB 以內），
官網新增或更新一筆出機紀錄，回傳官網的網址。服務費一律是 0、不帶客人資料。「從官網拿掉」會連照片一起刪。見 [api.md](api.md#內部-rpcwebsiteapi)。
照片只收 JPEG、PNG、WebP、GIF（**HEIC 不收**，大部分瀏覽器看不到），格式不對會回中文的錯誤訊息，寫出是哪張照片。

## 已知的限制

- 網站資料是一份 JSON，單一集合（例如文章）超過約 1.9MB 會存不進去
- 出機紀錄頁一次下載全部的出機紀錄（`/api/public/orders?limit=all`），筆數很多時會變慢；到時候要改成分頁或拆資料表
- 以前存過的文章，「更新日期」被存成存檔時間（舊的 bug），讀出來會顯示成發布日期；編輯一次、填好更新日期再存就好
- 沒有次數限制（rate limiting）
