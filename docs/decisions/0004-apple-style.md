# 0004 介面改成 Apple 風格：後台左側選單、前台 apple.com/tw/mac 的版面

- 狀態：採用
- 日期：2026-10-16（前台版面 2026-10-17）

## 背景

原本的介面是動態漸層背景、格線、極光、卡片光澤，後台上方兩張大卡（控制台、管理分頁）。使用者要改成 Apple 風格。

第一版（2026-10-16）只把顏色、字、按鈕換成 Apple 的（`styles/apple.css`），版面結構沒變，使用者覺得「沒有很 Apple 的感覺」。

## 決定

- 設計規格用 getdesign 的 Apple 分析（repo 根目錄的 [`DESIGN.md`](../../DESIGN.md)）：Action Blue `#0066cc` 是唯一的互動色、白和淺灰（`#f5f5f7`）、
  系統字體、膠囊按鈕、沒有裝飾性漸層和陰影
- **改結構，不只改顏色**（2026-10-17，`styles/apple-site.css`）：照 apple.com/tw/mac 的版面
  - 每一段是滿版區塊，白和淺灰交替，大標靠左
  - 導覽列是 44px 半透明細條、12px 小字
  - 推薦配單、近期出機、服務流程用 `components/Shelf.tsx` 的橫向捲動卡片列
  - footer 改成分欄
- **後台**改成左側固定選單（`components/AdminShell.tsx`）：出機紀錄、推薦配單、分類總覽、技術文章、網站文字；手機是上方分頁；分頁記在 `#hash`；
  「訂單管理」改名「出機紀錄」（真正的訂單在 DPOM）

## 代價

- CSS 是三層疊起來的（`App.css` → `apple.css` → `apple-site.css`），後面的蓋前面的；改樣式要看清楚是哪一層生效
- 要換風格時，`DESIGN.md` 和兩支 CSS 都要改，並新增一份 ADR 取代這份
- 橫向卡片列在電腦上要靠按鈕或觸控板捲動，卡片太多時不容易一眼看完
